# PCR Chart Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add an intraday PCR (PE OI ÷ CE OI) time-series line chart to the Premium tab of `/options`, below the existing four charts.

**Architecture:** All data is already available in `chartData` (per-candle `CE OI` / `PE OI`). One field (`PCR`) is added to the map pass that builds `chartData`, then a full-width chart card is inserted into the existing Premium tab JSX — no new files, no new API routes.

**Tech Stack:** React, Recharts (`LineChart`, `Line`, `ReferenceLine`, `ResponsiveContainer`), Tailwind CSS.

## Global Constraints

- File to modify: `rs_dashboard/components/OptionsCharts.tsx` only
- Follow existing patterns: `bg-zinc-900/60 border border-zinc-800 rounded-2xl p-5` card shell, shared `xAxisProps` / `gridProps` / `tooltipProps`, `fmtNum` formatter
- No text color opacity modifiers (e.g. no `text-white/70`) — use solid zinc colors
- Line color must match the existing PCR stat tile: emerald-400 (`pcr > 1.3`), red-400 (`pcr < 0.7`), yellow-400 (neutral)
- Chart visible only when `hasOiData` is true; empty state follows the OI chart pattern

---

### Task 1: Add PCR field to chartData and render PCR chart card

**Files:**
- Modify: `rs_dashboard/components/OptionsCharts.tsx`

**Interfaces:**
- Consumes: existing `chartData` array (each row has `CE OI?: number`, `PE OI?: number`)
- Produces: `chartData` rows gain `PCR: number | null`; new chart card rendered in Premium tab

- [ ] **Step 1: Add `PCR` to the `chartData` map**

Find the `chartData` IIFE (around line 438). Change the `return` inside the `.map()` from:

```ts
    return {
      ...row,
      VWAP: parseFloat((cumPV / cumV).toFixed(2)),
      'OI Diff': (row['PE OI'] ?? 0) - (row['CE OI'] ?? 0),
    };
```

to:

```ts
    return {
      ...row,
      VWAP: parseFloat((cumPV / cumV).toFixed(2)),
      'OI Diff': (row['PE OI'] ?? 0) - (row['CE OI'] ?? 0),
      PCR: (row['CE OI'] ?? 0) > 0
        ? parseFloat(((row['PE OI'] ?? 0) / (row['CE OI'] ?? 0)).toFixed(3))
        : null,
    };
```

- [ ] **Step 2: Derive the PCR line stroke color**

(These are the Tailwind emerald-400, red-400, yellow-400 hex values.)
