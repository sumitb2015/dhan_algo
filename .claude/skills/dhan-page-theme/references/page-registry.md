## Flags
| Flag | Meaning | Fix |
|---|---|---|
| `NO_HEADER` | no sticky titled header found | add the standard header (`header-anatomy.md`) |
| `NAVBAR_BARE` | `NavBar` is a bare first child with no title row | same |
| `NO_NAVBAR` | `NavBar` not rendered in the file | add it last in the header |
| `Z_LOW` / `Z_HIGH` | header z-index <= 10, or >= 40 | use `z-30` |
| `NO_TILE` | header has no icon tile | add the flat accent tile |
| `TILE_WHITE` | gradient tile with a `text-white` icon (dark glyph in white mode) | `text-oncolor` |
| `TEXT_500` | header text uses a `-500`/`-600` accent (not themed) | `-400` |
| `NO_DATA_CHIP` | file handles a data date but never renders `DATA:` | add the DATA chip |
| `NO_METADATA` | no tab title | thin server `page.tsx` with `metadata` |
| `DUP_ICON` | same lucide icon heads 3+ pages | pick a distinct icon (`icons-and-accents.md` section 4) |

`icon` `-` means none was detected inside the tile (the glyph may be an inline SVG or a variable), not that the page has
no icon.

`tier`: `flat` = accent tile (standard), `gradient` = legacy gradient tile, `neutral` = `bg-zinc` tile (a control or
Compass link), `no-tile`. `comp` `(inline page.tsx)` means the page keeps its whole UI in `page.tsx`.
